NIRDC Research and Development Backend
A comprehensive backend system for the National Innovation Research and Development Center (NIRDC) that manages research proposals, investment applications, and various user roles.

Project Overview
This system provides a robust API for managing research proposals, investment applications, and user accounts. It includes features for user authentication, document uploads, application tracking, and administrative functions.

Technologies Used
Node.js & Express: Backend framework
MongoDB: Database
AWS S3: File storage for documents and images
JWT: Authentication
Nodemailer: Email notifications
SMS Integration: Mobile verification
Prerequisites
Node.js (v14 or higher)
MongoDB
AWS S3 account
Gmail account for email notifications
SMS gateway account (for Sri Lankan phone verification)
